# souls-like text-rpg

learning C# and OOP by building a turn-based combat system

## current features
-  player and goblin classes with health / moves
-  game loop while both are active
-  random goblin move selection

## currently working on
- actually implementing combat
- figuring out player input
- making moves affect health

## what im learning
- classes and objects
- arrays and random numbers

## how to run
open in Visual Studio / VS Code and run as a C# console app or run with `dotnet run`
